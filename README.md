# vanhecke_2425_analysis
Analysing Brighton´s dutch centerback from 24/25 season

In this project I analysed JP Van Hecke after an astonishing Premier League 24725 season.

This was my first scouting report focused on one single player.

I started with a small player description and then I compared him alongside some of the best PL CBs
